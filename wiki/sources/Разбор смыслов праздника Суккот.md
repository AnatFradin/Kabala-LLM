## Основные темы

### Постоянное и временное жилище («Шамати» 96)

Выход из «постоянного жилища» (устойчивого, но застывшего духовного состояния) во «временное» (положение гостя, снова нуждающегося в направлении). Ушпизин — не только гости в сукке, но состояние самого человека: почувствовать себя гостем, а не хозяином. «Потребность прийти в чертог Творца» открывается только при живой нехватке, а не при уверенности «я уже там». Полный разбор — см. [[Отходы гумна и винодельни — Шамати 96]] (страница обновлена этим уроком).

### Четыре вида — символ разных людей (РАБАШ, «893. Плод цитрусового дерева»)

Этрог (вкус+запах) = праведники; лулав (вкус, без запаха) = средние (заповеди без духа Торы); мирт (запах, без вкуса) = дух Торы без заповедей; ива (ни вкуса, ни запаха) = простолюдины. Заповедь требует собрать все четыре — «Творец не доволен, пока все не соберутся в одно целое». Новая тема — см. [[Четыре вида — единство разных людей и разных состояний (РАБАШ, Шамати 85)]].

### Четыре вида — состояния внутри человека (Бааль Сулам, «Шамати» 85)

Те же четыре вида как этапы внутренней работы одного человека: лулав («сердце Творцу», принятие власти по принуждению), мирт («ветвь праотцев» — три линии), ива (работа без вкуса и запаха, всё равно с радостью — «буквы Единого Имени»). Уже разобрано на отдельной странице — см. [[Плод великолепного дерева — четыре вида — Шамати 85]].

### Синтез

«То, что существует между людьми, существует и внутри каждого из нас» — оба прочтения (люди / состояния) не противоречат друг другу; практический смысл для группы и вопросы для обсуждения — см. новую концепт-страницу.
